# Buscador de Películas (JavaScript)

App web que busca películas usando la API de OMDb.

## Funciones
- Buscar películas por nombre
- Filtro por año
- Ordenar por año y por título
- Paginación (anterior / siguiente)
- Ver detalles de una película
- Guardar favoritos (localStorage)
- Modo oscuro (se guarda)
- Botón limpiar

## Tecnologías
- HTML
- CSS
- JavaScript
- OMDb API
